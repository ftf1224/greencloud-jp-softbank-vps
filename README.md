## 软银线路实际表现如何：回程、超售和磁盘速度

先说线路，这是这个系列最大的卖点。第三方测评站 digvps 在 2026 年 7 月对软银版 500G 档的实测结论是：三网回程全部走 SoftBank，去程电信走 163、移动走 CMI、联通走 4837。对国内用户来说，回程全程软银意味着晚高峰看油管、拉文件的速度底线有保障，这也是「软银版」比同价位的普通线路版本更抢手的原因。

同一个测评给出的评级是 E4「尚可」，原话是：「从 CPU 跑分来看，这款产品的超售情况比较明显，不过考虑到它的定位是一款低价大盘机，整体还是相当有吸引力的。」翻译一下就是：CPU 性能别抱期待，买它就是买盘和线路。

磁盘性能可以用同系列机型的公开测试数据做参考：4K 随机读写大约 110 MB/s 上下，1M 块顺序读写能到 700 MB/s 出头。这个特征很典型——SATA 机械盘做 RAID-10，顺序吞吐够用，随机性能平庸。拿它挂 PT、做下载机、存备份和照片没问题；想跑数据库或者高并发的动态网站，这块盘会先让你失望。

另外提一句同机房的 IIJ 版本：价格和配置与软银版完全一致，但回程走 IIJ 网络，同一测评的原话是「就目前数据来看电信相当糟糕」。如果你认准软银，下单时看清楚机房后缀，别选错线路。

## 下单前必须接受的四个限制

这几条有的写在套餐页面上，有的藏在条款里，但每一条都会实际影响使用，竞品文章普遍没讲全。

1. **不退款。** 所有 Storage KVM 套餐页面都明确标注「No refund/money back on this plan」。25 美元虽然不多，但付了就没有反悔的余地，绿云在 2025 年周年庆期间的促销套餐同样执行这个规则。
2. **流量按双向计费。** 第三方收录时对软银版流量的标注是「In+Out」，也就是上传和下载都扣额度。500G 档的 1TB 月流量，双向合计摊到每天大约 34GB。做下载机够用，但如果你的场景是「上传大文件给别人反复下载」，实际可用量要按一半估算。
3. **只支持 Linux。** 没有 Windows 选项，面板是 VirtFusion，装 Debian、Ubuntu 这类发行版没障碍，想远程桌面挂 Windows 应用的可以关掉这个页面了。
4. **风控严格。** 绿云在早年的大盘鸡促销帖里就提醒过用户要用真实有效的地址下单，信息乱填有被砍单的风险。下单时地址、姓名老老实实填。

还有一条隐性成本要知道：大盘鸡系统盘只有 20–60GB NVMe，大头在 SATA 盘上。系统、Docker 镜像这些占系统盘的东西要省着用，数据目录记得挂到大盘上。

**软银版和 IIJ 版选哪个？**
